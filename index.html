24/7 Gratis Online Zet Gids (Render.com)

Host je eigen Trance Radar gratis in de cloud voor telefoon & PC toegang

Stap 1: Bewaar dit HTML-bestand

Sla deze pagina op je computer of telefoon op als index.html.

Stap 2: Gratis account op GitHub of Render

1. Maak een gratis account op GitHub.com en maak een nieuw (privé) repository aan.

2. Upload het bestand index.html hierin.

Stap 3: Koppelen aan Render Static Site

1. Ga naar Render.com en klik op New + → Static Site.

2. Selecteer je GitHub repository.

3. Render geeft je direct een unieke webadres (bijv. https://trance-vinyl-radar.onrender.com).

💡 Tip: Sla die link op als snelkoppeling op het startscherm van je iPhone of Android. De radar werkt dan exact als een native app!
